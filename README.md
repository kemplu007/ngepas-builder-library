# Ngepas Builder Library

Platform belajar programming dan startup building dengan analogi sederhana untuk orang yang belajar sambil membangun.

## Masalah yang ingin diselesaikan
Belajar programming sering terasa abstrak, terlalu cepat, dan membuat pemula bingung sebelum sempat membuat sesuatu yang nyata.

## Siapa yang dibantu
Orang Indonesia yang ingin membangun produk digital sambil memahami nalar programming secara pelan-pelan.

## Versi pertama
- Lesson JavaScript Fundamental
- Analogi kehidupan sehari-hari
- Progress, bookmark, dan catatan lokal
- Satu admin studio untuk menulis materi
